# Оборот CRM

CRM для компаний Узбекистана, которые продают, отгружают, монтируют и производят: заявка → счёт → оплата → отгрузка в одном обороте. Суммы в сумах, НДС 12%, ЭСФ вместо УПД, оплата через Payme и Click, реквизиты по ИНН/ОКЭД/МФО. Каждая из «30 возможностей CRM, которыми вы не пользуетесь» реализована как рабочий модуль, а не как заглушка. Без ключей внешних сервисов система работает в демо-режиме: все действия выполняются и логируются, наружу ничего не уходит. Подключаете ключ — тот же модуль начинает работать по-настоящему.

## Запуск

```bash
npm install
cp .env.example .env.local        # при желании впишите ключи
npm run setup                     # создать базу и заполнить демо-данными
npm run dev                       # http://localhost:3000
```

Вход: `admin@oborot.uz` / `admin123`. Другие роли: менеджер `jasur@oborot.uz`, производство `sherzod@oborot.uz`, бухгалтер `dilnoza@oborot.uz` — пароль `demo123`.

Продакшен: `npm run build && npm start`. База — SQLite-файл `data/crm.db` (переменная `DATABASE_URL`), документы — папка `storage/`.

## Архитектура

- `src/db/schema.ts` — схема данных (Drizzle, SQLite).
- `src/lib/integrations/*` — адаптеры внешних сервисов (Payme/Click, банки Узбекистана, Didox/Faktura.uz, Eskiz/Playmobile, OnlinePBX/Sipuni, реестр ЮЛ soliq.uz). Каждый адаптер читает настройки из раздела «Интеграции» (или переменных окружения) и переходит в демо-режим, если ключей нет.
- `src/lib/automations/*` — движок «событие → условия → действия». События публикуются через `emit()` из `src/lib/events.ts`.
- `src/lib/documents/*` — генерация PDF (pdf-lib, шрифт с кириллицей): счета, договоры, ЭСФ, акты, КП в сумах с НДС 12%.
- `src/lib/permissions.ts` — модель прав: область видимости, скрытые и read-only поля.
- `src/app/(app)/*` — разделы интерфейса, серверные компоненты + серверные функции.

## Переменные окружения

См. `.env.example`. Ключи интеграций можно задать и в интерфейсе (Интеграции → Настроить). `ANTHROPIC_API_KEY` включает ИИ-ответы, приём звонков и разбор команд бота; без ключа используется встроенный демо-режим.
